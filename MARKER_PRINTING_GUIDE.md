# 📱 Panduan Mencetak AR Markers

## 🎯 Cara Mencetak AR Markers

### 1. **Download Marker**
- Buka aplikasi AR di browser
- Klik hamburger menu (☰) di pojok kiri atas
- Scroll ke bawah untuk melihat section "AR Markers"
- Klik pada marker yang ingin Anda download
- Klik tombol "📥 Download Marker" yang muncul
- File PNG akan otomatis terdownload

### 2. **Persiapan Cetak**

#### **Ukuran Marker:**
- **Ukuran Standar**: 10cm x 10cm (100mm x 100mm)
- **Ukuran Minimum**: 8cm x 8cm
- **Ukuran Maksimum**: 15cm x 15cm

#### **Kertas yang Disarankan:**
- **Kertas Foto**: Kualitas terbaik, tahan lama
- **Kertas HVS 80gsm**: Kualitas baik, ekonomis
- **Kertas Karton**: Lebih tebal, lebih stabil
- **Hindari**: Kertas tipis atau kertas yang mudah sobek

### 3. **Pengaturan Printer**

#### **Printer Settings:**
```
- Paper Size: A4 atau Letter
- Quality: High/Photo Quality
- Color Mode: Color (Full Color)
- Paper Type: Photo Paper atau High Quality
- Margins: Minimum atau None
```

#### **Software yang Bisa Digunakan:**
- **Windows**: Paint, Photos, Microsoft Word
- **Mac**: Preview, Pages
- **Online**: Canva, GIMP, Photoshop Online

### 4. **Langkah-langkah Cetak**

#### **Menggunakan Paint (Windows):**
1. Buka file marker PNG dengan Paint
2. Klik "File" → "Print" → "Page Setup"
3. Set paper size ke A4
4. Set orientation ke Portrait
5. Set margins ke minimum
6. Klik "OK"
7. Klik "Print"

#### **Menggunakan Preview (Mac):**
1. Buka file marker PNG dengan Preview
2. Klik "File" → "Print"
3. Set paper size ke A4
4. Set scale ke 100%
5. Klik "Print"

#### **Menggunakan Microsoft Word:**
1. Buka Microsoft Word
2. Insert → Pictures → Select marker file
3. Resize gambar ke 10cm x 10cm
4. File → Print
5. Set paper size ke A4
6. Klik "Print"

### 5. **Tips Mencetak yang Baik**

#### **Kualitas Cetak:**
- ✅ Gunakan printer dengan resolusi minimal 300 DPI
- ✅ Pastikan tinta printer tidak habis
- ✅ Gunakan kertas berkualitas baik
- ✅ Hindari kertas yang sudah kusam atau kotor

#### **Akurasi Ukuran:**
- ✅ Ukur marker setelah dicetak dengan penggaris
- ✅ Pastikan ukuran 10cm x 10cm (±2mm)
- ✅ Jika terlalu kecil/besar, adjust scale di printer settings

#### **Kualitas Gambar:**
- ✅ Pastikan marker tidak blur atau pixelated
- ✅ Warna harus kontras (hitam-putih-emas)
- ✅ Border putih harus jelas terlihat

### 6. **Troubleshooting**

#### **Marker Terlalu Kecil:**
- Increase scale di printer settings ke 110-120%
- Pastikan paper size sudah benar

#### **Marker Terlalu Besar:**
- Decrease scale di printer settings ke 90-95%
- Check paper size settings

#### **Kualitas Buruk:**
- Ganti ke kertas foto
- Increase printer quality settings
- Bersihkan print head printer

#### **Warna Tidak Akurat:**
- Calibrate printer color
- Gunakan kertas yang sesuai dengan printer
- Check printer ink levels

### 7. **Penggunaan Marker**

#### **Setelah Dicetak:**
1. **Potong Marker**: Potong marker dengan rapi mengikuti border
2. **Laminating (Opsional)**: Laminating untuk melindungi marker
3. **Tempatkan di Permukaan Datar**: Letakkan di meja atau lantai yang rata
4. **Pencahayaan Baik**: Pastikan pencahayaan cukup (tidak terlalu terang/gelap)
5. **Stabilkan Marker**: Pastikan marker tidak bergerak saat digunakan

#### **Tips Penggunaan:**
- ✅ Gunakan di area dengan pencahayaan yang baik
- ✅ Pastikan marker tidak terlipat atau rusak
- ✅ Jaga jarak kamera 20-50cm dari marker
- ✅ Gerakkan kamera perlahan untuk tracking yang stabil

### 9. **FAQ (Frequently Asked Questions)**

#### **Q: Apakah bisa menggunakan marker yang dicetak hitam putih?**
A: Tidak disarankan. Marker membutuhkan kontras warna yang baik untuk deteksi yang akurat.

#### **Q: Berapa lama marker bisa digunakan?**
A: Tergantung kualitas kertas dan perawatan. Dengan kertas foto dan laminating, bisa bertahan berbulan-bulan.

#### **Q: Apakah bisa menggunakan marker di layar komputer/tablet?**
A: Tidak disarankan karena layar memiliki glare dan tidak stabil untuk tracking.

#### **Q: Bagaimana jika marker rusak atau hilang?**
A: Anda bisa download ulang marker dari aplikasi dan mencetak kembali.

#### **Q: Apakah bisa menggunakan marker yang lebih besar atau lebih kecil?**
A: Bisa, tapi ukuran 10cm x 10cm adalah yang optimal untuk deteksi dan stabilitas.
